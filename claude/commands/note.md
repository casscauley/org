Read the notes in this project's `backlog/notes/` folder. Each note is a markdown file with frontmatter, and any screenshots it references live in `backlog/notes/img/` named after the note's slug. Default to the newest note only, unless I say otherwise below.

Notes come in two kinds, and how I phrase the request tells you which:

- **Fix it now.** Do the work. The note was a handoff, not a record — so once the work is done, delete the note and every image it references, in the same commit as the fix.
- **File it for later.** Don't build anything. Promote the note into a curated task file at `backlog/<slug>.md` — what the code looks like today, what it should look like after, how to tell it worked — add it to `backlog/README.md`'s index, and delete the note. If this repo has no task files yet, leave the note in place to be committed instead.

If which one I mean isn't clear, ask before starting.
